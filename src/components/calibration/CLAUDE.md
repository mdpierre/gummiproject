# Calibration Component

## What This Does

The calibration phase runs 2–3 AI-generated warm-up questions at the start of every session to detect the child's reading tier. Tier detection informs LLM prompt complexity and patience window defaults for the rest of the session.

## Flow

1. Gummy introduces calibration warmly: *"Before we start, let's warm up! I'll ask you a couple of quick questions."*
2. Ask 2–3 questions (AI-generated, age-appropriate, topic-neutral)
3. Collect voice responses via Whisper STT
4. Score responses locally — detect reading tier
5. If `tierOverride` is set to anything other than `'auto'` in `SessionConfig`, skip this phase and use the override

## Tier Detection Logic

Calibration scores on three signals:

| Signal | How It's Measured |
|---|---|
| Response latency | Time from question end to first word spoken |
| Sentence completion | Did the child finish a full sentence? |
| Vocabulary match | Did the child use multi-syllabic words correctly? |

Scoring:

```ts
type CalibrationSignal = {
  responseLatencyMs: number;
  sentenceComplete: boolean;
  complexWordUsed: boolean;
};

function detectTier(signals: CalibrationSignal[]): ReadingTier {
  // early: high latency, low completion, no complex words
  // developmental: medium latency, partial completion, some complex words
  // fluent: low latency, full completion, complex words used
}
```

## AI-Generated Questions

Calibration questions are generated by the LLM with a dedicated prompt asking for simple, open-ended questions appropriate for ages 6–8. Questions should not be AI-literacy content — they're warm-up only (e.g., *"What did you have for breakfast?"* or *"What's your favorite animal?"*).

Fallback: a hardcoded set of 5 questions in case LLM call fails.

## Output

Calibration emits a `CalibrationResult` to `SessionContext`:

```ts
interface CalibrationResult {
  detectedTier: ReadingTier;
  signals: CalibrationSignal[];
}
```

## Timer Integration

The falling gummies timer runs during the timed reading passage (not calibration). However, calibration response latency feeds into tier detection and informs the patience window applied to the main session.
