# Session Component

## What This Does

The session component is the main loop of the app — it orchestrates story delivery, timed reading, comprehension Q&A, the patience window, critical thinking follow-ups, and reinforcement. Everything after onboarding and calibration lives here.

## Session Flow (Ordered)

```
1. Story Intro
   └─ Gummy reads the module story aloud (karaoke highlighting)

2. Timed Reading
   └─ Falling gummies timer runs while child reads passage aloud

3. Comprehension Question
   └─ Gummy asks a question about the passage

4. Patience Window
   └─ Balloon/bubble countdown before hint is offered
   └─ Gummy waits full window — child gets first attempt always

5. Answer Handling
   ├─ Correct → Confetti → "Why do you think that?" follow-up
   └─ Incorrect/Hinted → "Let's try that again together!" → repetition loop (1–2x)

6. Big Question (module close)
   └─ Open-ended, no wrong answer, Gummy celebrates any response

7. Session End
   └─ Gummy waves goodbye
   └─ PDF report generation is triggered
```

## Patience Window Mechanics

- Default: 8 seconds (configurable via `SessionConfig.patienceWindowMs`)
- IEP mode: 12–15 seconds
- During the window: avatar enters `thinking` state, balloon countdown shows subtly
- After window expires: Gummy offers one hint (generated by LLM based on the question)
- Gummy NEVER completes the child's in-progress sentence — only offers a nudge after silence

```ts
interface PatienceWindowProps {
  durationMs: number;
  onExpire: () => void;
  onChildSpoke: () => void; // cancels the countdown
}
```

## Karaoke Story Display

- Story text is shown word by word with highlight synced to TTS playback
- Use TTS `onboundary` event (Web Speech API) for word-level timing
- Fallback: manual timing based on estimated word duration if boundary events unreliable
- Font size: large, high contrast — optimized for 6–8 year old readers

## Critical Thinking Layer

After every correct answer (independent or hinted):
1. Fire: *"Why do you think that?"*
2. Wait patience window for response
3. Any response is celebrated — this is habit-building, not grading
4. Gummy occasionally adds: *"I learned that from books — where did you learn it?"*

## Reinforcement

| Outcome | Gummy Behavior |
|---|---|
| Independent correct | Confetti + specific praise + "Why do you think that?" |
| Hinted correct | Softer confetti + "Great job getting there!" + repetition prompt |
| Repeated incorrect | No negative framing — "That's tricky! Let's try together." + correct answer modeled |

## State Shape

```ts
interface SessionState {
  module: ModuleId;
  phase: 'story' | 'timed-read' | 'question' | 'patience' | 'followup' | 'big-question' | 'end';
  currentQuestionIndex: number;
  answers: AnswerRecord[];
  hintsUsed: number;
  timerResult: 'before' | 'after' | null; // relative to gummies falling
}
```

## Metrics Collection

The session component feeds `src/lib/metrics/` continuously:
- Record every answer: timestamp, question, response text, hinted, latency
- Record patience window outcomes: expired or child-initiated
- Record speech pace samples from Whisper output
- These are consumed at session end by the PDF report generator
