# Report Component

## What This Does

At session end, a parent-facing PDF report is generated entirely client-side using `@react-pdf/renderer`. Nothing is transmitted to a server. The parent downloads or prints the PDF directly from the browser.

## Report Sections

### 1. Header
- Gummy logo + chosen color accent
- Session date and duration
- Child's name (from `SessionConfig.childName`)
- Module covered (e.g., "What is AI?")

### 2. Reading Tier
- Tier detected during calibration: Early / Developmental / Fluent
- Tier movement indicator: Improved / Stable / Needs Support
- Brief plain-language description of what the tier means

### 3. Comprehension Score
- Questions answered independently (no hint)
- Questions answered with a hint
- Questions not answered
- Visual bar or icon-based display (not a percentage grade — parent-friendly framing)

### 4. Speech Metrics
- Average speaking pace (words per minute, approximate)
- Average pause length between words
- Sentence completion rate (completed unaided vs. trailed off)
- Framed positively: these are observations, not grades

### 5. Critical Thinking Engagement
- Number of "Why do you think that?" follow-ups answered
- Big question: child's verbatim transcribed response
- Framed as: *"Here's what [name] said when Gummy asked the big question..."*

### 6. Gummy's Session Note
- 1–2 AI-generated sentences summarizing the session in parent-friendly language
- Generated by the LLM at session end using session metrics as input
- Example: *"Jimmy worked hard today and answered 3 out of 4 questions on his own. He showed great thinking when asked why AI can't know what happened at school today!"*

### 7. Privacy Footer
Must always appear, verbatim:
> *"Voice data was processed on this device and was not transmitted or stored. This report was generated locally and contains no data from external servers."*

## Implementation

Use `@react-pdf/renderer` — it has better mobile Safari support than jsPDF.

```tsx
// components/report/SessionReport.tsx
import { Document, Page, Text, View, StyleSheet } from '@react-pdf/renderer';

interface SessionReportProps {
  config: SessionConfig;
  metrics: SessionMetrics;
  gummyNote: string; // AI-generated at session end
}
```

The report is rendered to a blob in-browser and surfaced as a download link. Do not upload or transmit the blob.

## Trigger

Report generation is triggered when the session enters the `end` phase:
1. Collect final `SessionMetrics` from the metrics store
2. Make one LLM call to generate `gummyNote` (pass metrics summary, get 1–2 sentences back)
3. Render the PDF component to blob
4. Display download button to parent

## Design Notes

- Use the child's chosen color as an accent in the report
- Keep it one page if possible — parents should be able to read it in 60 seconds
- No letter grades, no fail language — frame everything as developmental observations
- Include the module title prominently so parents can discuss it with the child
